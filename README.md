# 铜壶滴漏 TONGHU-DILOU — 机构复刻 No.17

元代广州铜壶滴漏(1316,冼运行等造,现存中国国家博物馆):日壶→月壶→
星壶→受水壶四级阶梯,日壶溢流保水头恒定,滴孔流量 Q = C·A·√(2gh) 恒定,
受水壶中浮舟托铜箭(百刻分度)匀速上升报时。B 键查看阶梯总图。

## 机构与验算

```
尺寸(演示值):
  四级壶   日壶(Ø0.60 最高)→ 月壶 → 星壶 → 受水壶(Ø0.52)
  水头     h = 0.18 m 恒定(日壶溢流)
  滴孔     A = 8 mm²,流量系数 C = 0.62

流量与箭速(载入期断言):
  Q = C·A·√(2gh) = 0.62×8e-6×√(3.53) = 9.3 ml/s(恒定)
  浮箭上升速度 v = Q/A受水壶 ≈ 5.1 mm/s
  百刻 = 一昼夜(演示压缩 864:1 → 100s)
  载入模拟 100s 恰走百刻(±1.5 刻)断言
```
